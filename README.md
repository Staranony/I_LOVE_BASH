### 2026.10.08 added tyt.sh 
This is file which you can extract video titles in youtube in bash! \n
Superuseful. you don't need any dependencies. just type in your terminal "./tyt.sh [CHANNEL NAME]" That's it \n

if you want to just extract video names, not shorts add last /videos in your terminal \n
e.g "./tyt.sh [CHANNEL NAME]/videos"
